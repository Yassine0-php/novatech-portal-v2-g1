première étape:
1/création branch main (git branch main) (si besoin)
2/aller sur la branch main (git checkout main)
2/l'intégrateur est sur main puis créer la branch develop (git branch develop)
3/chaque personne créer ça propre branch avec son nom ex:(git branch votre prenom)
4/sur votre branch perso créer vos branches de tickets ex (git branch fix/modifier_css) voir Format pour les branches

deuxième étapes:
règle étape:
1/push que quand tout les ticket sont fini est valider
2/comuniquer à l'intégrateur à quel moment push
3/push uniquement sur la branch develop
4/seulement l'intégrateur qui pourra faire le merge au main
