Organisation du développement

La DSI NovaTech utilise Git afin d'assurer :

  • la traçabilité des modifications ;
  • la stabilité du portail ;
  • la collaboration entre équipes ;
  • la validation progressive des fonctionnalités.

Workflow Git

main

Branche stable représentant la version validée du portail.

develop

Branche d’intégration utilisée pour assembler les fonctionnalités.

feat/*

Branche utilisée pour développer une nouvelle fonctionnalité.

fix/*

Branche utilisée pour corriger un bug ou un incident.

Processus de contribution

  1. Créer une branche depuis develop
  2. Traiter un seul ticket par branche
  3. Committer régulièrement
  4. Ouvrir une Pull Request
  5. Attendre validation avant fusion
